# Runtime moved to retro-ai-runtime

The C++ inference library, game adapters, model data, build instructions, and C++
workflows now live in
[retro-ai-runtime](https://github.com/MatPoliquin/retro-ai-runtime).

```bash
git clone https://github.com/MatPoliquin/retro-ai-runtime.git
```

Follow that repository's README to build and test the runtime. General training,
evaluation, and model export remain in stable-retro-scripts. Earlier runtime
history remains available in this repository's Git history.
